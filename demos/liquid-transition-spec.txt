2. WHAT IT IS
-------------
A full-screen screen-to-screen transition, previewed over two real game screens:
  screen A = Profile (img/screen-profile.jpg), screen B = Match History (img/screen-match-history.jpg).
A transparent WebGL canvas sits over the screen images. The effect floods in from an origin side, covers the screen
completely, holds (the MTX logo shows in the middle), then carries on in the SAME direction and leaves, revealing screen B.
The screen images swap (A hidden, B shown) at timeline 0.4, while the screen is fully covered, so the swap is never seen.

Three styles share one timeline, origin and palette:
  0 Toon puffs   hard-edged round "cloud puff" lobes; flat dark body; a solid single-colour edge band with its own lobes
  1 Black fog    (SAVED) dark smoky body; the marble paint colour only in a band just behind each moving front; soft front
  2 Full marble  the whole body is poured-acrylic marble (black ground, coloured streaks, white skin, gloss, droplets)
Visual references for the marble: poured / fluid acrylic art, black ground with coral-red, pink, electric blue and a
little gold, thin white skins where paint meets black, small droplets. Toon puffs reference: a mask sketch with a white
body, a yellow lobed edge band and black uncovered area, all hard-edged.

4. TIMELINE (timeline t goes 0 -> 1 over Duration seconds, linear)
------------------------------------------------------------------
  TL = { in: [0, 0.4], out: [0.6, 1], logo: [0.38, 0.47], logoOut: [0.53, 0.62], swap: 0.4 }
  seg(t, [a, b]) = clamp((t - a) / (b - a), 0, 1)
  easeInOut(x)   = x < 0.5 ? 2x² : 1 - (-2x + 2)² / 2
  uIn  = easeInOut(seg(t, TL.in))     front of the incoming effect, 0 -> 1
  uOut = easeInOut(seg(t, TL.out))    front of the leaving effect, 0 -> 1, travelling the same direction as the in
  logo = Logo at hold ? min(seg(t, TL.logo), 1 - seg(t, TL.logoOut)) : 0
         -> #logo opacity = logo, transform translate(-50%,-50%) scale(0.94 + 0.06·logo); also uPool = logo
  screen B shown when t >= 0.4 (A hidden), else A shown.
  Tag stage name: t < 0.4 "Flow in", t < 0.6 "Hold", else "Flow out".
  Verified coverage (alpha > 250 share of pixels): Black fog/Full marble 0.2≈51%, 0.3–0.7 = 100%, 0.8≈47%, 0.95 = 0%;
  Toon puffs 0.2≈53%, 0.39–0.62 = 100%, 0.8≈48%, 1 = 0%.


5. DATA
-------
ORIGINS (away = direction from the origin across the screen in uv, y up; null = from the centre outward):

  6 Bottom left [1,1] · 7 Bottom [0,1] · 8 Bottom right [-1,1]
  JS passes uCenterOrigin = away ? 0 : 1 and uAway = away || [1, 0].

PALETTES (ink · warm · warm2 · cool · accent · hi · edge):
  0 Reference   #050608 · #ff5b4f · #e9426f · #1f86ff · #f2a945 · #f6f1ea · #ff5b4f
  1 Red vs blue #07070c · #ff0027 · #ff4d6d · #3a63ff · #f6df2f · #fff7e1 · #ff0027
  2 MTX gold    #0b0d12 · #f96000 · #ff0027 · #f6df2f · #fff7e1 · #fff7e1 · #f6df2f   <- SAVED
  3 Night ice   #04060c · #5214df · #8a5cff · #19a4ff · #9be7ff · #e8f6ff · #19a4ff
  ink = the dark body / black ground · warm, warm2, cool = streak colours · accent = occasional streaks · hi = white skin,
  rim, gloss tint · edge = Toon puffs edge band colour. Colours are passed as vec3 0..1 (hex / 255).

Uniforms set every frame (JS -> shader):
  uTime (accumulated flow time), uAspect (canvas w/h), uPxH (canvas height px), uScale, uWarp, uStretch, uBands,
  uAccentAmt, uGloss, uEdge (white skin), uSpeck, uFrontWarp, uSoft, uRim, uBand, uPool, uIn, uOut, uCenterOrigin,
  uAway, uFog (style 2 ? 0 : 1), uToon (style 0 ? 1 : 0), uPuff, uEdgeW, uInk, uWarm, uWarm2, uCool, uAccent, uHi, uEdgeCol.
  Canvas: WebGL1, { premultipliedAlpha: false, alpha: true }, size = CSS size x min(2, devicePixelRatio),
  one full-screen triangle pair, vUv origin bottom-left. The OES_standard_derivatives extension is requested (gloss uses
  dFdx/dFdy; without it the gloss block is skipped by #ifdef).


6. SHADER ALGORITHM (fragment; st = (vUv - 0.5) with st.x *= aspect, so screen height = 1 unit)
------------------------------------------------------------------------------------------------
Noise: hash(p) = fract(sin(dot(p, (127.1, 311.7))) * 43758.5453); value noise with smoothstep fade;
  fbm = 5 octaves, rotation/scale matrix mat2(1.6, 1.2, -1.2, 1.6), gain 0.5;
  fbm3 = 3 octaves, same, divided by 0.875 (smoother, used for the warp fields).
aw = normalize(uAway.x * aspect, uAway.y) · t = uTime.

6.1 Marble field (all styles compute it; Toon puffs ignores it)
  Flow frame: fd = centre origin ? normalize(1, -0.6) : aw; fl = (dot(st, fd), dot(st, perp(fd))).
  p = (fl.x / uStretch, fl.y) * uScale - (t * 0.35 / uStretch, 0)          // streaks stretched along the flow, streaming
  q = (fbm3(p + 0.10t), fbm3(p + (5.2, 1.3) - 0.08t))
  r = (fbm3(p + uWarp·q + (1.7, 9.2) + 0.12t), fbm3(p + uWarp·q + (8.3, 2.8) - 0.10t))
  f = fbm(p + uWarp·r)                                                      // domain warping (fbm of fbm of fbm)
  band = f * uBands + r.x * 1.5; k = fract(band); idx = mod(floor(band), 6)
  zone = smoothstep(0.36, 0.64, fbm(st * uScale * 0.3 + (3.1, 7.7) + 0.02t))   // big warm vs cool areas
  main1 = mix(warm, cool, zone); main2 = mix(warm2, cool*0.8 + hi*0.2, zone)
  Streak by idx: 0, 2, 4 = black ground (paint 0); 1 = main1; 3 = accent if hash(floor(band), 3) > 1 - uAccentAmt else main2;
  5 = main2. Paint body shading: col *= 0.55 + 0.5·sin(k·π).
  White skin: skin = 1 - smoothstep(uEdge·0.4, uEdge, min(k, 1-k)); col = mix(col, hi, skin·paint·0.85).
  Ground tint: black streaks get + main1 · 0.06 · (1 - smoothstep(0, 0.5, min(k, 1-k))).
  Gloss (if derivatives): slope = (dFdx(f), dFdy(f)) · uPxH · 0.05; n = normalize(-slope, 1);
    spec = pow(max(dot(reflect(-normalize(-0.45, 0.55, 0.7), n), (0,0,1)), 0), 28); col += spec·uGloss·mix(1, col, 0.35).
  Droplets: sc = st·uScale·9, cell grid; jittered centre (0.2 + 0.6·hash); radius 0.05 + 0.14·hash;
    shown if hash(cell) < uSpeck·0.35; colour hi on paint, main1·1.25 on black; mix 0.9.

6.2 Front (Black fog and Full marble)
  g = centre ? length(st) / length(0.5·aspect, 0.5) : (dot(st, aw) / (0.5·aspect·|aw.x| + 0.5·|aw.y|) + 1) / 2    // 0 at origin .. 1 far side
  gw = g + (fbm(st·uScale·1.2 + 2q + 0.15t) - 0.5) · 2·uFrontWarp                                             // fingers
  thIn  = mix(-fw - uSoft, 1 + fw + uSoft, uIn); thOut = same with uOut       (fw = uFrontWarp)
  cover = 1 - smoothstep(thIn - uSoft, thIn + uSoft, gw); keep = smoothstep(thOut - uSoft, thOut + uSoft, gw); alpha = cover·keep
  live = uIn < 0.999; liveOut = 0.001 < uOut < 0.999
  Black fog (uFog = 1): edgeAmt = max(live·exp(-max(thIn - gw, 0)/uBand), liveOut·exp(-max(gw - thOut, 0)/uBand));
    smoke = ink·(0.5 + 0.9·fbm(st·2.2 + 1.5q + 0.2t)) + main1·0.02; col = mix(col, mix(smoke, col, edgeAmt), uFog)
    -> body is dark smoke, marble colour only within ~uBand behind each moving front.
  Rim: rim = (exp(-|gw - thIn| / (2·uSoft + 0.008))·live + same for thOut·liveOut)·alpha; col = mix(col, hi, clamp(rim·uRim·0.7)).
  Logo pool: pr = length(st·(0.8, 1)) + (fbm(3.5st + 0.25t) - 0.5)·0.18;
    pool = uPool·(1 - smoothstep(0.16 + 0.12·uPool, 0.34 + 0.12·uPool, pr)); col = mix(col, ink, pool·0.94).
  Output: vec4(clamp(col), alpha), straight alpha.

6.3 Toon puffs (uToon = 1) — replaces the output
  smin(a, b, k) = polynomial smooth minimum.
  puffSDF(x, th, M, ahead, seed): signed distance, negative = covered.
    E = centre ? length(0.5·aspect, 0.5) : 0.5·aspect·|aw.x| + 0.5·|aw.y|
    pos = mix(centre ? -M : -E - M, E + M, th) + ahead           // front position along the flow
    blobs on a grid of cell size C = uPuff, 3x3 neighbourhood: id = cell + offset + seed;
      centre c = (id - seed + 0.5 + ((hash(id), hash(id + 7.3)) - 0.5)·0.8)·C; radius r = C·(0.55 + 0.45·hash(id + 3.1))
      dc = (centre ? length(c) : dot(c, aw)) - pos; re = r·clamp(0.5 - dc/r, 0, 1)   // blob grows as the front reaches it
      dB = min(dB, length(x - c) - re) for re > 0
    dPlane = (centre ? length(x) : dot(x, aw)) - pos; return smin(dPlane, dB, 0.12·C)
  M = 1.3·uPuff + uEdgeW; aa = 1.5 / uPxH
  dIn  = puffSDF(st, uIn, M, 0, 0);    dInE = min(dIn - 0.3·uEdgeW, puffSDF(st, uIn, M, uEdgeW, 31.7))   // edge band with its own lobes
  dG   = puffSDF(st, uOut, M, 0, 57.1); dGE  = min(dG - 0.3·uEdgeW, puffSDF(st, uOut, M, uEdgeW, 83.9))
  masks m(d) = 1 - smoothstep(-aa, aa, d): inB = m(dIn), inE = m(dInE), gn = m(dG), gnE = m(dGE)
  edgeT = clamp(max(inE - inB, gnE - gn)); body = mix(ink·(0.6 + 0.6·fbm(2.2st + 0.2t)), ink, 1 - uFog)
  Output: vec4(mix(body, edgeCol, edgeT), inE·(1 - gn))
  -> in: [origin] body | solid edge band | uncovered screen; out (same direction): [origin] screen B | edge band | body.


7. BEHAVIOUR RULES (keep these when changing anything)
-------------------------------------------------------
  - The out never reverses: it continues away from the origin (first covered = first revealed).
  - The screen swap happens only under 100% cover (t = 0.4).
  - All three styles share timeline, origin, palette; style-only sliders simply have no effect in the other styles.
  - Colours always come from the palette uniforms; no hard-coded colours in the shader.
  - Dark game theme; UI labels in English; glyph/kbd before the label on buttons.

  const FRAG = `
#ifdef GL_OES_standard_derivatives
#extension GL_OES_standard_derivatives : enable
#endif
precision highp float;
varying vec2 vUv;
uniform float uStretch, uAccentAmt, uFog, uBand;   // uFog 1 = black fog body with coloured edges, 0 = full marble
uniform float uToon, uPuff, uEdgeW;               // Toon puffs: lobe size and edge band width, in screen-height units
uniform vec3 uEdgeCol;
uniform float uTime, uAspect, uPxH, uScale, uWarp, uBands, uGloss, uEdge, uSpeck, uFrontWarp, uSoft, uRim, uPool;
uniform float uIn, uOut, uCenterOrigin;   // front progress 0..1 (in: paint arrives, out: paint leaves, same direction)
uniform vec2 uAway;                       // from the origin across the screen (uv, y up)
uniform vec3 uInk, uWarm, uWarm2, uCool, uAccent, uHi;

float hash(vec2 p) { return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453); }
float noise(vec2 p) {
  vec2 i = floor(p), f = fract(p), u = f * f * (3.0 - 2.0 * f);
  return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x), mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
}
float fbm(vec2 p) {
  float v = 0.0, a = 0.5;
  mat2 m = mat2(1.6, 1.2, -1.2, 1.6);
  for (int i = 0; i < 5; i++) { v += a * noise(p); p = m * p; a *= 0.5; }
  return v;
}
float fbm3(vec2 p) {   // smoother: for the warp fields, so the paint pours instead of crumpling
  float v = 0.0, a = 0.5;
  mat2 m = mat2(1.6, 1.2, -1.2, 1.6);
  for (int i = 0; i < 3; i++) { v += a * noise(p); p = m * p; a *= 0.5; }
  return v / 0.875;
}

float smin(float a, float b, float k) { float h = clamp(0.5 + 0.5 * (b - a) / k, 0.0, 1.0); return mix(b, a, h) - k * h * (1.0 - h); }
// signed distance to the puffy front (negative = covered). The straight (or round) front sits at progress th;
// round blobs on a jittered grid grow as the front reaches their centre, so the edge bubbles while it moves.
// ahead = push this front further forward (the edge band), seed = a different set of blobs
float puffSDF(vec2 x, vec2 aw, float th, float M, float ahead, float seed) {
  float E = uCenterOrigin > 0.5 ? length(vec2(0.5 * uAspect, 0.5)) : 0.5 * uAspect * abs(aw.x) + 0.5 * abs(aw.y);
  float pos = mix(uCenterOrigin > 0.5 ? -M : -E - M, E + M, th) + ahead;
  float C = uPuff, dB = 1e5;
  vec2 cell = floor(x / C);
  for (int j = -1; j <= 1; j++) for (int i = -1; i <= 1; i++) {
    vec2 id = cell + vec2(float(i), float(j)) + seed;
    vec2 c = (id - seed + 0.5 + (vec2(hash(id), hash(id + 7.3)) - 0.5) * 0.8) * C;
    float r = C * (0.55 + 0.45 * hash(id + 3.1));
    float dc = (uCenterOrigin > 0.5 ? length(c) : dot(c, aw)) - pos;
    float re = r * clamp(0.5 - dc / r, 0.0, 1.0);
    if (re > 0.0) dB = min(dB, length(x - c) - re);
  }
  float dPlane = (uCenterOrigin > 0.5 ? length(x) : dot(x, aw)) - pos;
  return smin(dPlane, dB, C * 0.12);
}

void main() {
  vec2 st = vUv - 0.5;
  st.x *= uAspect;
  vec2 aw = normalize(vec2(uAway.x * uAspect, uAway.y));
  float t = uTime;

  // ---- marble: fbm warped by fbm warped by fbm, streaming away from the origin ----
  // streaks are stretched along the flow (uStretch) so they read as long pours, like the references
  vec2 fd = uCenterOrigin > 0.5 ? normalize(vec2(1.0, -0.6)) : aw;
  vec2 fl = vec2(dot(st, fd), dot(st, vec2(-fd.y, fd.x)));
  vec2 p = vec2(fl.x / uStretch, fl.y) * uScale - vec2(t * 0.35 / uStretch, 0.0);
  vec2 q = vec2(fbm3(p + t * 0.10), fbm3(p + vec2(5.2, 1.3) - t * 0.08));
  vec2 r = vec2(fbm3(p + uWarp * q + vec2(1.7, 9.2) + t * 0.12), fbm3(p + uWarp * q + vec2(8.3, 2.8) - t * 0.10));
  float f = fbm(p + uWarp * r);
  float band = f * uBands + r.x * 1.5;   // streaks follow the warped field
  float k = fract(band), idx = mod(floor(band), 6.0);
  // big colour zones like the references: warm on one side, cool on the other
  float zone = smoothstep(0.36, 0.64, fbm(st * uScale * 0.3 + vec2(3.1, 7.7) + t * 0.02));
  vec3 main1 = mix(uWarm, uCool, zone), main2 = mix(uWarm2, uCool * 0.8 + uHi * 0.2, zone);
  vec3 col = uInk; float paint = 1.0;
  if (idx < 1.0 || (idx > 1.5 && idx < 3.0) || (idx > 3.5 && idx < 5.0)) paint = 0.0;   // every other streak is the black ground
  else if (idx < 2.0) col = main1;
  else if (idx < 4.0) col = hash(vec2(floor(band), 3.0)) > 1.0 - uAccentAmt ? uAccent : main2;   // a few streaks run in the accent colour
  else col = main2;
  col *= paint > 0.5 ? 0.55 + 0.5 * sin(k * 3.14159) : 1.0;                           // rounded, poured body
  // thin white skin where paint meets the black, as in poured acrylic
  float skin = 1.0 - smoothstep(uEdge * 0.4, uEdge, min(k, 1.0 - k));
  col = mix(col, uHi, skin * paint * 0.85);
  col += (1.0 - paint) * main1 * 0.06 * (1.0 - smoothstep(0.0, 0.5, min(k, 1.0 - k)));   // the black ground picks up a little colour near the paint

  // wet gloss from the slope of the streak field
#ifdef GL_OES_standard_derivatives
  vec2 slope = vec2(dFdx(f), dFdy(f)) * uPxH * 0.05;   // slope of the smooth field, not the bands, so the sheen rolls over the streaks
  vec3 nrm = normalize(vec3(-slope, 1.0));
  float spec = pow(max(dot(reflect(-normalize(vec3(-0.45, 0.55, 0.7)), nrm), vec3(0.0, 0.0, 1.0)), 0.0), 28.0);
  col += spec * uGloss * mix(vec3(1.0), col, 0.35);
#endif

  // speckles: little droplets, light on the black, white on the paint
  vec2 sc = st * uScale * 9.0, sid = floor(sc);
  vec2 sp = sid + 0.2 + 0.6 * vec2(hash(sid + 1.3), hash(sid + 2.7));
  float dropR = 0.05 + 0.14 * hash(sid + 4.1);
  float drop = (1.0 - smoothstep(dropR * 0.6, dropR, length(sc - sp))) * step(hash(sid), uSpeck * 0.35);
  col = mix(col, paint > 0.5 ? uHi : main1 * 1.25, drop * 0.9);

  // ---- the front: a directional (or radial) gradient pushed around by fbm, so the paint arrives in fingers ----
  float g = uCenterOrigin > 0.5 ? length(st) / length(vec2(0.5 * uAspect, 0.5))
                                : (dot(st, aw) / (0.5 * uAspect * abs(aw.x) + 0.5 * abs(aw.y)) + 1.0) * 0.5;
  float fw = uFrontWarp;
  float gw = g + (fbm(st * uScale * 1.2 + q * 2.0 + t * 0.15) - 0.5) * fw * 2.0;
  float thIn = mix(-fw - uSoft, 1.0 + fw + uSoft, uIn), thOut = mix(-fw - uSoft, 1.0 + fw + uSoft, uOut);
  float cover = 1.0 - smoothstep(thIn - uSoft, thIn + uSoft, gw);
  float keep = smoothstep(thOut - uSoft, thOut + uSoft, gw);
  float a = cover * keep;
  float live = 1.0 - step(0.999, uIn), liveO = step(0.001, uOut) * (1.0 - step(0.999, uOut));
  // black fog: the body is dark smoke, the marble colour only lives in a band just behind each moving front
  float edgeAmt = max(live * exp(-max(thIn - gw, 0.0) / uBand), liveO * exp(-max(gw - thOut, 0.0) / uBand));
  vec3 smoke = uInk * (0.5 + 0.9 * fbm(st * 2.2 + q * 1.5 + t * 0.2)) + main1 * 0.02;
  col = mix(col, mix(smoke, col, edgeAmt), uFog);
  // lit leading edge on each moving front
  float rim = (exp(-abs(gw - thIn) / (uSoft * 2.0 + 0.008)) * live + exp(-abs(gw - thOut) / (uSoft * 2.0 + 0.008)) * liveO) * a;

  float pool = uPool * (1.0 - smoothstep(0.16 + 0.12 * uPool, 0.34 + 0.12 * uPool, pr));

    gl_FragColor = vec4(mix(body, uEdgeCol, edgeT), inE * (1.0 - gn));
    return;
  }
  gl_FragColor = vec4(clamp(col, 0.0, 1.0), a);
}`;

  //#endregion
